{% include t.html en="How to write a diagram" zh="写图示的规则" %}

  • Inline the SVG with class="diagram" and a viewBox; never hard-code colors.
  • Text: d-title, d-label, d-small, d-muted, d-mono; color modifiers d-accent / d-green / d-red / d-amber / d-purple.
  • Shapes: d-panel, d-panel-2, d-box (+ accent / green / …). Lines: d-line (+ color, dashed).
  • Arrowheads: put {% include diagram-markers.html id="unique-name" %} inside the SVG, then use marker-end="url(#unique-name-arrow-accent)". Every SVG on a page needs its own id.
  • In Markdown posts, wrap the SVG in <div class="figure" markdown="0"> so it isn't parsed as Markdown.
  • 内联 SVG，加 class="diagram" 和 viewBox，不要写死颜色。
  • 文字：d-title、d-label、d-small、d-muted、d-mono；颜色：d-accent / d-green / d-red / d-amber / d-purple。
  • 形状：d-panel、d-panel-2、d-box（可加 accent / green / …）。线条：d-line（可加颜色、dashed）。
  • 箭头：在 SVG 里写 {% include diagram-markers.html id="唯一名" %}，线条用 marker-end="url(#唯一名-arrow-accent)"。同一页每张图的 id 都要不同。
  • 在 Markdown 文章里，用 <div class="figure" markdown="0"> 包住 SVG，避免被当成 Markdown 解析。
